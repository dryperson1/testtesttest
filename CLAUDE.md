## How the owner wants to be talked to

- Always explain what you are doing in normal English.
- Do not show unexplained terminal commands, shell syntax, raw Git output or compiler errors.
- Before major changes, explain what you are changing, why, and which files are affected.
- Afterward, explain what changed and whether it worked.
- Assume the owner understands basic programming concepts but not obscure terminal syntax.
